# Changelog

All notable changes to the Wyssn application will be documented in this file.

## [1.2.0] - 2025-03-15

### Added

- New speech recognition feature with improved accuracy
- Multilingual support (English, German, French, Japanese, Korean, Chinese)
- User authentication with Kinde
- Voice command shortcuts for common actions
- Dark mode support across all application views
- Export functionality for conversation histories
- Custom themes selection in user preferences

### Changed

- Improved UI responsiveness across all device sizes
- Updated React to version 19
- Enhanced suggestion algorithm using latest NLP techniques
- Redesigned dashboard with more intuitive layout
- Optimized database queries for faster response times
- Restructured navigation menu for better accessibility
- Improved error handling with more informative messages

### Fixed

- Bug in language selector that caused incorrect language detection
- Performance issues on mobile devices
- Text rendering in some languages with complex character sets
- Memory leak in real-time audio processing component
- Session timeout issues during extended use
- Incorrect timestamp display in different timezones
- Broken links in help documentation

### Security

- Implemented enhanced encryption for stored voice data
- Added two-factor authentication option
- Updated dependencies to address security vulnerabilities
- Improved GDPR compliance with better data management controls

## [1.1.0] - 2025-02-10

### Added

- Batch processing capabilities for audio files
- Integration with popular calendar applications
- Custom keyboard shortcuts
- Offline mode for basic functionality
- Browser extension for quick access
- Audio visualization during recording
- Shareable link generation for collaborative sessions

### Changed

- Migrated from REST API to GraphQL for more efficient data fetching
- Updated audio processing library for better performance
- Improved search functionality with advanced filters
- Enhanced mobile experience with touch-optimized controls
- Reduced application bundle size by 30%
- Updated documentation with more examples and tutorials
- Reorganized settings panel for easier navigation

### Fixed

- Audio distortion in noisy environments
- Synchronization issues between devices
- Unresponsive UI elements in Safari browser
- Incorrect word boundaries in certain languages
- Data persistence issues after application updates
- Inconsistent styling across different themes
- Login failures with certain OAuth providers

### Deprecated

- Legacy PDF export format (to be removed in 1.3.0)
- Old notification system (will be replaced in next release)
